Più file alla volta nella schermata **FFMPEG**, e la prima versione per **Linux**.

## Cosa cambia

- **Più file insieme nella schermata FFMPEG**: trascinando nella casella più file (o scegliendoli insieme con "Scegli file…") la casella diventa una lista, che scorre con la rotellina. "Converti" li converte in sequenza, uno alla volta, dall'alto in basso, con le stesse scelte per tutti.
  - **Righe**: ogni file ha la sua riga con nome, durata e formato, la barra di avanzamento e il cestino per toglierlo. A conversione finita la riga dice il nome del file creato e ha il pulsante che lo mostra nella cartella. La barra in basso segue l'intera lista ("File 4 di 6").
  - **Aggiungere e togliere**: altri file si aggiungono trascinandoli nella casella o con "Aggiungi file…"; un file già in lista non viene aggiunto due volte. "Svuota" toglie tutte le righe. I file sul disco non vengono toccati.
  - **File esclusi**: un file che con quelle scelte non si può convertire (un video senza audio quando chiedi un mp3, un file che ffmpeg non sa leggere) resta fuori, e la sua riga dice perché. Se una conversione non riesce la lista prosegue con le altre.
  - **Ferma e riprendi**: "Ferma" interrompe il file in corso e lascia in lista quelli non ancora fatti; "Converti" riparte da quelli, senza rifare i file già pronti. Cambiando una scelta tutti i file tornano da convertire.
- **Linux**: l'app esce anche come AppImage, un file solo con dentro Qt e tutti gli strumenti, come i pacchetti per Mac e Windows. Funziona con Wayland e con X11, ha la sua icona e, installata con `cmake --install`, la sua voce nel menu delle applicazioni.
- **macOS**: il pacchetto ora funziona da macOS 15 in poi (quello della 0.5.0 chiedeva macOS 27), perché viene costruito in automatico su GitHub Actions come quelli per Windows e Linux.
- **Con un solo file** la schermata FFMPEG è quella di prima. Una differenza: trascinare un altro file ora lo aggiunge alla lista, invece di prendere il posto del primo. Per sostituirlo c'è "Cambia file…".

## Limiti noti

- Le scelte valgono per tutta la lista: non si può dare un formato diverso a ogni file.
- I file vengono convertiti nell'ordine in cui sono stati aggiunti, e l'ordine non si può cambiare.
- Si trascinano i file, non le cartelle: una cartella trascinata viene ignorata.
- Il tempo rimasto della lista è una stima fatta sulla durata dei file: con file molto diversi tra loro (un video da ricodificare e un audio) può sbagliare di molto.
- Con file molto lunghi la compressione abbassa molto la qualità (3 ore in 16 MB sono circa 11 kbps in mono). Oltre circa 4 ore in 16 MB l'app dice che il file è troppo lungo.
- I miglioramenti dell'audio sono stati verificati su file di prova sintetici, non ancora giudicati a orecchio su registrazioni parlate.
- Cambiando lingua la finestra viene ricreata: le liste si svuotano (l'app chiede conferma prima).
- Per Spotify e per i profili Instagram la barra indica solo che il download è in corso: spotDL e instaloader non comunicano la percentuale.
- Instagram limita molto chi non è collegato, e TikTok chiede il login per i profili interi: per questi casi servono le opzioni di login della modalità avanzata.

## Download

- **macOS** (Apple Silicon, macOS 15 o successivo): `DefDownloader-macos-arm64.dmg`, poi trascina l'app in Applicazioni
- **Windows** (64 bit): `DefDownloader-windows-x64.zip`, estrai la cartella e avvia `DefDownloader.exe`
- **Linux** (x86_64, glibc 2.39 o successiva: Arch, CachyOS, Fedora 40, Ubuntu 24.04…): `DefDownloader-linux-x86_64.AppImage`, rendilo eseguibile (`chmod +x`) e avvialo. Se non parte perché manca FUSE, avvialo con `--appimage-extract-and-run`.

Tutti includono già gli strumenti: non serve installare altro. Se sul computer sono già installati, l'app usa quelli.

Le app non sono firmate da uno sviluppatore registrato, quindi al primo avvio il sistema chiede conferma:

- **macOS**: Impostazioni → Privacy e sicurezza → "Apri comunque"
- **Windows**: "Ulteriori informazioni" → "Esegui comunque"

I tre pacchetti sono compilati e provati in automatico su GitHub Actions: ognuno viene avviato senza altri programmi installati, per controllare che trovi gli strumenti al suo interno. La lista di più file è stata provata su Linux (CachyOS, KDE) con file di prova. L'AppImage è stata avviata anche a mano su CachyOS; i pacchetti di questa versione per Mac e per Windows non sono ancora stati provati a mano.
